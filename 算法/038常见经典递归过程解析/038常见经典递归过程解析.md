# 1. 字符串的全部子序列

测试链接 : https://www.nowcoder.com/practice/92e6247998294f2c933906fdedbc6e6a



## 代码

```java
import java.util.HashSet;
import java.util.Set;

public class Code01_Subsequences {
    public static String[] generatePermutation (String str) {
        char[] s = str.toCharArray();
        Set<String> set = new HashSet<>();
        StringBuilder path = new StringBuilder();
        f1(s, 0, path, set);

        int m = set.size();
        String[] ans = new String[m];
        int i = 0;
        for (String cur : set) {
            ans[i++] = cur;
        }
        return ans;
    }

    public static void f1(char[] s, int i, StringBuilder path, Set<String> set) {
        if (i == s.length) {
            set.add(path.toString());
        }else {
            path.append(s[i]);
            f1(s, i+1, path, set);
            path.deleteCharAt(path.length() - 1);
            f1(s, i+1, path, set);
        }
    }

    public static String[] generatePermutation2 (String str) {
        char[] s = str.toCharArray();
        Set<String> set = new HashSet<>();
        f2(s, 0, new char[str.length()], 0, set);
        int m = set.size();
        String[] ans = new String[m];
        int i = 0;
        for (String cur : set) {
            ans[i++] = cur;
        }
        return ans;
    }

    public static void f2(char[] s, int i, char[] path, int size, Set<String> set) {
        if (i == s.length) {
            set.add(String.valueOf(path,0,size));
        }else {
            path[size] = s[i];
            f2(s, i+1, path, size+1, set);
            f2(s, i+1, path, size, set);
        }
    }

}
```



## 思路



#### 1. 【一句话核心】

**“二叉决策树”**：对于字符串里的每一个字符，你只有两个选择：**① 要它**，或者 **② 不要它**。一路选到底，就是一条子序列。

#### 2. 【图解原理：为什么是递归？】

想象你在走迷宫，或者在画一棵树。假设字符串是 `"abc"`。

从起点开始，对于字符 `'a'`，你有两条路；走完 `'a'` 的路，对于 `'b'` 又有两条路……

![image-20260129222954862](038%E5%B8%B8%E8%A7%81%E7%BB%8F%E5%85%B8%E9%80%92%E5%BD%92%E8%BF%87%E7%A8%8B%E8%A7%A3%E6%9E%90.assets/image-20260129222954862.png)

**看图说明：**

- **层级 (Level)**：每一层代表输入字符串的一个字符（第0层看'a'，第1层看'b'……）。
- **分支**：
  - **左边（绿色）**：选择“**要**”当前字符 (`path.append`).
  - **右边（红色）**：选择“**不要**”当前字符 (什么都不做).
- **叶子节点**：到底部（`i == length`）时，路径上收集到的就是最终结果。

------

#### 3. 【难点攻破：什么是“回溯” (Backtracking)？】

在 `f1` 方法中，最让你头疼的应该是那句 `path.deleteCharAt(...)`。

**为什么要删？**

想象你只有一个 **共享笔记本 (StringBuilder path)**。

1. 你走左边的路（“要 a”），在笔记本上写了个 `'a'`。
2. 接着你走遍了左边所有的路，收集完了所有包含 'a' 的结果。
3. 现在你要**退回到路口**，准备走右边的路（“不要 a”）。
4. **关键点**：在你走右边之前，你必须把笔记本上写的 `'a'` **擦掉**！否则，你带着写着 `'a'` 的笔记本去走“不要 a”的路，结果就全乱了。

这就是 **“恢复现场”**。

![image-20260129223109924](038%E5%B8%B8%E8%A7%81%E7%BB%8F%E5%85%B8%E9%80%92%E5%BD%92%E8%BF%87%E7%A8%8B%E8%A7%A3%E6%9E%90.assets/image-20260129223109924.png)

**看图说明（f1 的执行流程）：**

1. **进坑**：`append('a')` -> 笔记本变 `"a"` -> 递归下去。
2. **触底**：到了底部，存下结果。
3. **回退**：函数返回，回到上一层。
4. **填坑（恢复现场）**：**`deleteCharAt`** -> 把 `'a'` 擦掉，笔记本变回 `""`。
5. **换路**：带着干净的笔记本，去走“不要 'a'”的那条路。

------

#### 4. 【代码逐行精读】

##### 写法一：经典回溯法 (`f1`)

```java
// i: 当前来到第几个字符做决定
// path: 全局共享的笔记本，记录沿途的决定
public static void f1(char[] s, int i, StringBuilder path, HashSet<String> set) {
    // 1. Base Case (触底)
    // 所有的字符都做完决定了，把笔记本上的内容存下来
    if (i == s.length) {
        set.add(path.toString());
    } else {
        // --- 分支 1：要当前字符 s[i] ---
        path.append(s[i]);        // 1. 在笔记本上写下字符
        f1(s, i + 1, path, set);  // 2. 带着这个字，去下一层做决定
        
        // --- 核心：恢复现场 (Backtracking) ---
        // 刚才“要”的路走完了，现在要退回来，准备走“不要”的路。
        // 必须把刚才写上去的 s[i] 擦掉！
        path.deleteCharAt(path.length() - 1); 

        // --- 分支 2：不要当前字符 s[i] ---
        f1(s, i + 1, path, set);  // 3. 笔记本保持原样（因为擦过了），去下一层
    }
}
```

##### 写法二：数组覆盖法 (`f2`)

这个写法没有显式的 `delete`，为什么也能对？

因为它用了 `size` 变量来控制“有效区域”。

```java
// path: 一个固定长度的数组
// size: 这里的 size 就像一个“光标”，光标左边的是有效内容
public static void f2(char[] s, int i, char[] path, int size, HashSet<String> set) {
    if (i == s.length) {
        set.add(String.valueOf(path, 0, size));
    } else {
        // --- 分支 1：要当前字符 ---
        path[size] = s[i]; // 直接在光标位置写字
        f2(s, i + 1, path, size + 1, set); // 光标往后移一格 (size + 1)

        // --- 分支 2：不要当前字符 ---
        // 注意：这里没有擦掉 path[size] 里的字，也没有 delete。
        // 而是直接传入了旧的 size。
        // 这意味着：下一层如果有新字符，会直接【覆盖】掉当前位置的字。
        // 如果没有新字符，最终截取结果时只截取到 size，后面的脏数据会被无视。
        f2(s, i + 1, path, size, set);
    }
}
```

------

#### 5. 【算法操作技巧】

- **HashSet 去重**：题目说子序列本身可能有重复（比如 "aba" 会生成两个 "a"），直接扔进 HashSet，利用 Set 的特性自动去重，省去了手动判断的麻烦。
- **数组代替 StringBuilder**：`f2` 比 `f1` 快，因为 `StringBuilder` 涉及对象的创建和动态扩容，而 `char[]` 是固定内存。且 `f2` 利用**覆盖**代替了**删除**，少了一步操作。

------

#### 6. 【复习闪卡 (Flashcard)】

1. **Q: 为什么递归里需要 `path.deleteCharAt`？**
   - **A:** 因为 `path` 是**引用传递**（大家共用一个），如果不删掉，就会把“左分支”的数据带到“右分支”去，导致结果错误。这叫**恢复现场**。
2. **Q: 这一题的递归决策树是什么样子的？**
   - **A:** 每个节点分两叉：左边是 `Include` (要)，右边是 `Exclude` (不要)。深度是字符串长度。
3. **Q: `f2` 方法为什么不需要显式恢复现场？**
   - **A:** 因为它通过 `size` 控制有效范围。走“不要”的分支时，`size` 不增加，下一层写入时会直接**覆盖**掉旧数据，相当于隐式删除了。



# 2. 返回数组的所有组合

测试链接 : https://leetcode.cn/problems/subsets-ii/



## 代码

```java
public static List<List<Integer>> subsetsWithDup(int[] nums) {
    List<List<Integer>> ans = new ArrayList<>();
    Arrays.sort(nums);
    f(nums, 0, new int[nums.length], 0, ans);
    return ans;
}

public static void f(int[] nums, int i, int[] path, int size, List<List<Integer>> ans) {
    if (i == nums.length) {
        List<Integer> cur = new ArrayList<>();
        for (int j = 0; j < size; j++) {
            cur.add(path[j]);
        }
        ans.add(cur);
    }else {
        int j = i + 1;
        while (j < nums.length && nums[i] == nums[j]) {
            j++;
        }
        f(nums,j,path,size,ans);

        for (; i < j; i++) {
            path[size++] = nums[i];
            f(nums,j,path,size,ans);
        }
    }
}
```



## 思路

**LeetCode 90. 子集 II (Subsets With Dup)**。

你之所以觉得难，是因为普通的子集问题是“这个元素我要还是不要”，是二选一。

但这里有重复元素（比如两个 `2`），如果还简单地“要还是不要”，就会出现两个一模一样的 `[2]`，导致重复。

这份代码用了一种非常聪明的 **“分组（批处理）”** 思想来解决这个问题。



#### 1. 【一句话核心】

**“打包批发”**：先把数组排序，让相同的数挨在一起。遇到一堆相同的数（比如三个 `2`），不要一个一个做决定，而是把它们看做一个**“大礼包”**，决定权变成：**我不拿 `2`、我拿一个 `2`、我拿两个 `2`、还是我拿三个 `2`？**

#### 2. 【图解原理：为什么普通递归会重？】

假设输入 `[1, 2, 2]`。

如果不去重，普通的递归会把第一个 `2` 当作 "2A"，第二个 `2` 当作 "2B"。

- 选 "2A" -> 结果 `[1, 2]`

- 选 "2B" -> 结果 `[1, 2]`

  **看，重复了！**

#### 3. 【图解原理：分组递归怎么做？】

我们先排序，变成 `[1, 2, 2]`。

递归过程不再是针对“第 i 个数”，而是针对**“这一组数”**。

![image-20260129223835182](038%E5%B8%B8%E8%A7%81%E7%BB%8F%E5%85%B8%E9%80%92%E5%BD%92%E8%BF%87%E7%A8%8B%E8%A7%A3%E6%9E%90.assets/image-20260129223835182.png)

**看图说明：**

- **第一层 (i=0)**：面对数字 `1`。它只有一个。
  - 选择：拿 0 个，或拿 1 个。
- **第二层 (i=1)**：面对数字 `2`。**代码发现后面还有一个 `2`，于是把它们圈起来变成一组 `{2, 2}`。**
  - 此时选择变成了**枚举数量**：
  - **分支 A**：一个 `2` 都不拿 (跳过这一组)。
  - **分支 B**：拿 1 个 `2`。
  - **分支 C**：拿 2 个 `2`。
- 这样生成的子集就是：`[]`, `[1]`, `[2]`, `[1, 2]`, `[2, 2]`, `[1, 2, 2]`。完全没有重复！

------

#### 4. 【代码逐行精读】

```java
public static void f(int[] nums, int i, int[] path, int size, List<List<Integer>> ans) {
    // Base Case: 所有的数字（或者说所有的组）都看过了
    if (i == nums.length) {
        List<Integer> cur = new ArrayList<>();
        for (int k = 0; k < size; k++) {
            cur.add(path[k]);
        }
        ans.add(cur);
    } else {
        // --- 核心逻辑开始 ---
        
        // 1. 划定边界：找出当前这组数哪里结束？
        // j 从 i+1 开始向后找，只要 nums[j] 和 nums[i] 一样，就继续找
        // 循环结束后，nums[i...j-1] 这一段就是一模一样的数
        int j = i + 1;
        while (j < nums.length && nums[i] == nums[j]) {
            j++;
        }
        // 此时，j 指向了【下一个不同数值】的开头。

        // 2. 选择一：这一组数，我一个都不要！
        // 直接跳到 j (下一组的开头)，path 和 size 都不变
        f(nums, j, path, size, ans);

        // 3. 选择二、三、四...：我要 1 个，我要 2 个...
        // 这是一个循环，从 1 个开始拿，一直拿到这一组结束
        for (; i < j; i++) {
            path[size++] = nums[i]; // 把当前数加入路径，size+1
            // 【关键点】递归去下一层时，依然是传 j ！
            // 意思是：我拿了 k 个当前数之后，剩下的当前数我都不要了，直接去审视下一组数。
            f(nums, j, path, size, ans);
        }
    }
}
```

#### 5. 【代码逻辑追踪 (Trace)】

没问题！我们用 `[1, 2, 2]` 这个例子，来一场**显微镜级别**的代码逻辑追踪。

这个例子的关键点在于：**第一层处理不重复的 `1`，第二层处理重复的 `[2, 2]`**。

我们将 `nums` 排序好：`[1, 2, 2]`，长度 `len = 3`。

初始调用：`f(nums, i=0, path, size=0, ans)`



##### **第一阶段：处理 `i=0` (数字 1)**

1. **分组定界**：
   - 当前 `i=0`，`nums[0] = 1`。
   - 程序运行 `while` 循环寻找 `j`。因为 `nums[1]` 是 2（不等于 1），循环直接停止。
   - **结果**：`j = 1`。说明 `nums[0...0]` 这一组只有一个 `1`。
2. **分支 A：这一组“一个都不拿” (不要 1)**
   - **操作**：直接递归下一层 `f(nums, j=1, path, size=0, ans)`。
   - **含义**：跳过数字 1，去处理后面的数字。
   - *(后续进入第二阶段的分支 A 系列)*
3. **分支 B：这一组“拿 1 个” (要 1)**
   - **操作**：进入 `for` 循环。
   - `path[0] = 1`，`size` 变为 1。
   - 递归 `f(nums, j=1, path, size=1, ans)`。
   - *(后续进入第二阶段的分支 B 系列)*

------

##### **第二阶段：处理 `i=1` (数字 2, 2)**

这里是**核心中的核心**。无论你是从上面的“分支 A”还是“分支 B”进来，都会遇到同样的逻辑，只是 `path` 前缀不同。我们以 **分支 A (前缀为空 `[]`)** 进来的情况为例：

当前状态：`i=1`，`nums` 剩下 `[2, 2]`。

1. **分组定界 (Batching)**：
   - 当前 `nums[1] = 2`。
   - 程序运行 `while` 循环找 `j`：
     - `nums[2]` 也是 2，`j` 继续 `++`。
     - `j` 变成 3，到达数组末尾。
   - **结果**：`j = 3`。说明 `nums[1...2]` 是一组相同的 `2`。

此时，代码面临**三个选择**（对应循环）：

1. **选择 1：这组 `2`，我一个都不要！**
   - **代码**：直接调用 `f(nums, j=3, ...)`。
   - **结果**：`i=3` 到底了，收集结果 **`[]`**。
2. **选择 2：这组 `2`，我要拿 1 个！**
   - **代码**：进入 `for` 循环的第一轮。
   - `path[size] = 2` -> `path` 变成 `[2]`。
   - **关键递归**：`f(nums, j=3, ...)`。注意这里直接跳到了 `j=3`，**绝不会**再去单独处理第二个 2。
   - **结果**：`i=3` 到底了，收集结果 **`[2]`**。
3. **选择 3：这组 `2`，我要拿 2 个！**
   - **代码**：`for` 循环继续，`i` 从 1 变 2。
   - `path[size] = 2` -> `path` 变成 `[2, 2]`。
   - **关键递归**：`f(nums, j=3, ...)`。
   - **结果**：`i=3` 到底了，收集结果 **`[2, 2]`**。

------

##### **分支 B 的后续 (前缀是 `[1]`)**

逻辑完全一样，只是大家的 `path` 里一开始就坐着一个 `1`。

1. **一个都不要** -> 结果 **`[1]`**
2. **拿 1 个 `2`** -> 结果 **`[1, 2]`**
3. **拿 2 个 `2`** -> 结果 **`[1, 2, 2]`**

------

##### 最终收集到的所有结果

将所有分支的“叶子节点”汇总：

1. `[]`
2. `[2]`
3. `[2, 2]`
4. `[1]`
5. `[1, 2]`
6. `[1, 2, 2]`

##### 总结这个例子的精髓

请注意看代码中的 `f(nums, j, ...)`。

- 当我们决定拿 **1 个** `2` 时，我们把 `2` 放入 `path`，然后直接跳到了 `j=3`（数组结束）。
- 这意味着，我们**永远不会**产生“处理完第一个 2，然后递归进去再单独面对第二个 2”的情况。
- **因为如果递归进去再面对第二个 2，就会产生“选了第一个2”和“选了第二个2”这种重复情况。**
- **直接跳到 `j`**，就是强迫你一次性把这堆重复的数字“批发处理”完：要么拿1个，要么拿2个……绝不回头！

#### 6. 【算法操作技巧】

- **排序是前提**：必须先 `Arrays.sort(nums)`。如果不排序，相同的数不在一起，这个分组逻辑就废了。
- **直接跳 `j`**：不管是“一个不要”，还是“要 n 个”，递归传参时下标永远是 `j`（下一组的开头）。这保证了我们处理完当前这组 `2` 之后，绝不会再回头看剩下的 `2`，彻底杜绝了重复。

#### 7. 【复习闪卡 (Flashcard)】

1. **Q: 解决子集查重问题的最关键一步是什么？**
   - **A:** **排序**。让相同的元素相邻，方便分组处理。
2. **Q: 这段代码是用什么逻辑避免重复的？**
   - **A:** **分组（Batch）逻辑**。对于重复的数字，不是一个个决策，而是作为一组，枚举“拿0个、拿1个……拿k个”，一次性处理完。
3. **Q: 变量 `j` 的作用是什么？**
   - **A:** `j` 是**“下一组不同数值的起始位置”**。无论当前这组数拿几个，递归往后走时都要直接跳到 `j`。



# 3. 没有重复项数字的全排列

测试链接 : https://leetcode.cn/problems/permutations/



## 代码

```java
import java.util.ArrayList;
import java.util.List;

/**
 * @Title: Code03_Permutations
 * @Author Wood
 * @Package PACKAGE_NAME
 * @Date 2026/1/26 22:23
 * @description:
 */
public class Code03_Permutations {
    public static List<List<Integer>> permute(int[] nums) {
        List<List<Integer>> ans = new ArrayList<>();
        f(nums, 0, ans);
        return ans;
    }

    public static void f(int[] nums, int i, List<List<Integer>> ans) {
        if (i == nums.length) {
            List<Integer> cur = new ArrayList<>();
            for (int num : nums) {
                cur.add(num);
            }
            ans.add(cur);
        }else {
            for (int j = i; j < nums.length; j++) {
                swap(nums, i, j);
                f(nums, i + 1, ans);
                swap(nums, i, j);
            }
        }
    }

    public static void swap(int[] arr, int i, int j) {
        int tmp = arr[i];
        arr[i] = arr[j];
        arr[j] = tmp;
    }
}
```



## 思路

#### 1. 【一句话核心】

**“站位交换法”**：把数组看作 N 个坑位，用 `i` 指针指向当前要决定的坑位，然后让 `i` 后面的所有数字（包括 `i` 自己）轮流跟 `i` 交换，换上来谁，谁就坐这个坑，定好后继续递归下一个坑。

#### 2. 【算法技巧操作】

- **In-Place 操作**：不需要额外的 `visited` 数组来标记“哪个数字用过了”。
  - `i` 左边（`0` 到 `i-1`）：是**已确定**的排列前缀。
  - `i` 及右边（`i` 到 `end`）：是**待选**的候选人集合。
- **对称回溯**：
  - 进递归前 `swap(i, j)`：把候选人 `j` 换到位置 `i` 上（上位）。
  - 递归后 `swap(i, j)`：把人换回去（恢复现场），好让下一个候选人也能和原始状态的 `i` 位置交换。

#### 3. 【图解原理】

假设输入数组为 `[1, 2, 3]`。

- **Level 0** (`i=0`)：决定谁放在第 1 个位置。
  - 自己跟自己换 (`1` 在首位) -> 递归
  - 跟 `2` 换 (`2` 在首位) -> 递归
  - 跟 `3` 换 (`3` 在首位) -> 递归

![image-20260129230325607](038%E5%B8%B8%E8%A7%81%E7%BB%8F%E5%85%B8%E9%80%92%E5%BD%92%E8%BF%87%E7%A8%8B%E8%A7%A3%E6%9E%90.assets/image-20260129230325607.png)





**图解说明：**

1. **向下箭头 (Swap & Recurse)**：表示选择。比如在根节点 (`i=0`)，`j=1` 的分支表示选择让 `nums[1]`（即数字 2）和 `nums[0]` 交换。数组变成 `[2, 1, 3]`，然后递归进入下一层 `i=1`。
2. **红色曲线箭头 (Restore Swap)**：表示回溯。递归调用返回后，必须执行一个完全一样的交换操作，把数字换回去。例如，从 `[2, 1, 3]` 递归回来后，红色箭头指示把 1 和 2 换回来，恢复成 `[1, 2, 3]`。这样在根节点的下一次循环 (`j=2`) 时，才能正确地基于原始状态把 3 换到第一个位置。
3. **叶子节点**：当 `i` 到达数组末尾时，当前的数组顺序就是一个完整的排列结果。

#### 4. 【代码逐行精读】

```java
public static void f(int[] nums, int i, List<List<Integer>> ans) {
    // 1. Base Case: i 越界了，说明 0~length-1 所有位置都定好了
    if (i == nums.length) {
        List<Integer> cur = new ArrayList<>();
        // 收集当前数组的状态作为一种结果
        for (int num : nums) {
            cur.add(num);
        }
        ans.add(cur);
    } else {
        // 2. 核心循环：j 从 i 开始，意味着 i 后面的每一个数都有机会来到 i 位置
        for (int j = i; j < nums.length; j++) {
            
            // [动作] 把 j 位置的数换到 i 位置（试探：让 nums[j] 来当主角）
            // 当 i == j 时，就是自己跟自己换，保持原样
            swap(nums, i, j);
            
            // [递归] i 位置定好了，去决定 i+1 位置
            f(nums, i + 1, ans);
            
            // [回溯] 恢复现场！
            // 把刚才换过来的数还回去，把数组变回这次循环开始前的样子
            // 这样下一次循环 j++ 时，基础状态才是对的
            swap(nums, i, j);
        }
    }
}
```

#### 5. 【死记硬背点 / 易错点】

1. **循环起点**：`int j = i`（从自己开始），**不是** `0`，也**不是** `i + 1`。
   - 如果是 `0`：会把前面定好的数换乱。
   - 如果是 `i+1`：会漏掉“自己留在当前位置”的情况。
2. **收集结果**：在 Base Case 里，必须 `new ArrayList<>()` 并把数据拷进去。如果直接 `ans.add(Arrays.asList(nums))`（假设泛型匹配），加进去的是引用。后面回溯会把所有引用指向的数据都改回原样，最后你会得到一堆空或者初始状态的列表。
3. **交换两次**：递归前 swap 一次，递归后必须 swap 一模一样的参数回来。

#### 6. 【复习闪卡 (Flashcard)】

1. **Q: 这种解法中，`nums` 数组被分成了哪两部分？**
   - A: `0 ~ i-1` 是已决定的排列前缀；`i ~ length-1` 是还没使用的待选集合。
2. **Q: 为什么要进行第二次 `swap`？**
   - A: **恢复现场**。保证在尝试下一个 `j` 之前，数组的顺序和刚进入这一层时一样，防止状态污染。
3. **Q: 循环条件 `for (int j = i; ...)` 中 `j=i` 的含义是什么？**
   - A: 表示当前位置 `i` 的数字保持不动（自己和自己交换），作为一种排列的可能性。

# 5. 用递归函数逆序栈

## 代码

```java
import java.util.Stack;

public class Code05_ReverseStackWithRecursive {
    public static void reverse(Stack<Integer> stack) {
        if (stack.isEmpty()) {
            return;
        }

        int num = bottomOut(stack);
        reverse(stack);
        stack.push(num);
    }

    // 栈底元素移除掉，上面的元素盖下来
    // 返回移除掉的栈底元素
    public static int bottomOut(Stack<Integer> stack) {
        int ans = stack.pop();
        if (stack.isEmpty()) {
            return ans;
        }else {
            int last = bottomOut(stack);
            stack.push(ans);
            return last;
        }
    }

    public static void main(String[] args) {
        Stack<Integer> stack = new Stack<Integer>();
        stack.push(1);
        stack.push(2);
        stack.push(3);
        stack.push(4);
        stack.push(5);
        reverse(stack);
        while (!stack.isEmpty()) {
            System.out.println(stack.pop());
        }
    }

}
```





## 思路

这段代码在工程上没有意义（直接新建一个栈倒进去更快），但它是 **理解“系统栈”与“数据栈”交互** 以及 **递归思维** 的绝佳训练场。

### 1. 【一句话核心】

**“利用系统栈来记忆数据”**：通过递归函数的调用栈（System Stack）来隐式地存储所有的局部变量，从而把数据栈（Data Stack）里的元素“抽”出来悬空，最后再按照相反的顺序“放”回去。

### 2. 【两大核心函数解析】

想要逆序一个栈，我们需要解决两个原子问题：

1. **如何拿到栈底元素并保持其他元素不动？** -> `bottomOut`
2. **如何利用这个能力完成逆序？** -> `reverse`

#### A. `bottomOut` (抽底函数)

- **功能**：移除并返回栈底元素，同时保持栈中剩余元素的相对顺序不变。
- **原理**：
  - 把当前栈顶 `pop` 出来存在局部变量 `ans` 里。
  - **递归调用**自己，去处理剩下的栈。
  - 等递归返回了（拿到栈底了），再把 `ans` **`push` 回去**。
  - **物理意义**：就像你在一摞书里抽最下面那本。你把上面的书一本本拿起来（pop），拿到最底下的书后，再把手里拿起来的书原样放回去（push）。

#### B. `reverse` (主逆序函数)

- **功能**：将栈彻底逆序。
- **原理**：
  - 调用 `bottomOut` 拿到当前的栈底元素 `num`（此时栈里少了一个元素）。
  - **递归调用** `reverse` 去处理剩下的栈。
  - 等递归结束（子栈已经逆序好了），把 `num` **`push` 进去**。
  - **物理意义**：
    1. 抽出最底下的 1。
    2. 对剩下的 [2, 3] 进行逆序 -> 变成 [3, 2]。
    3. 把 1 盖在 [3, 2] 上面 -> 变成 [3, 2, 1]。

------

### 3. 【超详细图解：过程推演】

假设初始栈 `stack` 从顶到底为：`[3, 2, 1]`。

目标：变成 `[1, 2, 3]`。

#### 第一阶段：宏观视角 (`reverse` 的执行)

递归就像洋葱，我们要一层层剥开看。

- **Layer 1 (reverse)**:
  - 调用 `bottomOut`。
  - **得到 `num = 1`** (栈底)。
  - 此时栈剩：`[3, 2]`。
  - **递归调用 `reverse`** (暂停当前执行，进入 Layer 2)。
  - *(等待 Layer 2 回来后，执行 `stack.push(1)`)*
  - **Layer 2 (reverse)**:
    - 调用 `bottomOut`。
    - **得到 `num = 2`** (当前栈底)。
    - 此时栈剩：`[3]`。
    - **递归调用 `reverse`** (暂停，进入 Layer 3)。
    - *(等待 Layer 3 回来后，执行 `stack.push(2)`)*
    - **Layer 3 (reverse)**:
      - 调用 `bottomOut`。
      - **得到 `num = 3`**。
      - 此时栈剩：`[]` (空)。
      - **递归调用 `reverse`**。
        - **Layer 4**: 栈空，直接 `return`。
      - **Layer 3 继续执行**：`stack.push(3)`。
      - 此时栈：`[3]`。
      - Layer 3 结束。
  - **回到 Layer 2**:
    - 执行 `stack.push(2)`。
    - 此时栈：`[3, 2]` (注意 3 在底，2 在顶)。
    - Layer 2 结束。
- **回到 Layer 1**:
  - 执行 `stack.push(1)`。
  - 此时栈：`[3, 2, 1]` (3在底，1在顶)。
  - **任务完成！**

------

#### 第二阶段：微观视角 (`bottomOut` 是怎么工作的？)

这是最难理解的部分。假设现在栈是 `[3, 2, 1]` (栈顶是 3)，我们要取 1。

**调用 `bottomOut(stack)`**

```
[系统调用栈 System Stack]             [数据栈 Data Stack]
(向下生长，保存每一层的局部变量)        (向右生长，最右是栈顶)

1. 进入 bottomOut 第一层
   ans = stack.pop() -> 3            栈状态: [1, 2]
   调用 bottomOut 第二层... (等待)

    2. 进入 bottomOut 第二层
       ans = stack.pop() -> 2        栈状态: [1]
       调用 bottomOut 第三层... (等待)

        3. 进入 bottomOut 第三层
           ans = stack.pop() -> 1    栈状态: [] (空)
           栈空了！这是 Base Case。
           return 1 (作为 last)
           (第三层结束)

    2. 回到 bottomOut 第二层
       接收返回值 last = 1
       stack.push(ans) -> push 2     栈状态: [2]
       return last (1)
       (第二层结束)

1. 回到 bottomOut 第一层
   接收返回值 last = 1
   stack.push(ans) -> push 3         栈状态: [2, 3]
   return last (1)
   (第一层结束)

---------------------------------------------------
最终结果：
1. 返回了 1 (原来的栈底)。
2. 栈变成了 [2, 3] (原来的 3, 2 顺序没变，只是 1 没了)。
```

### 4. 【代码逐行精读】

```java
public static int bottomOut(Stack<Integer> stack) {
    // 1. 先把栈顶拿下来，记在心里(系统栈局部变量里)
    int ans = stack.pop(); 
    
    // 2. Base Case: 如果拿走之后栈空了，说明刚才拿的 ans 就是栈底
    if (stack.isEmpty()) {
        return ans;
    } else {
        // 3. 递归：如果栈不空，让兄弟函数去下面找栈底
        int last = bottomOut(stack); 
        
        // 4. 恢复现场：兄弟找完回来了，我得把自己刚才拿走的 ans 放回去
        // 这样保证除了栈底没了，其他元素的顺序没乱
        stack.push(ans);
        
        // 5. 交差：把兄弟找到的栈底，往上传递
        return last;
    }
}
```

<br>

```java
public static void reverse(Stack<Integer> stack) {
    if (stack.isEmpty()) {
        return;
    }
    // 1. 抽取：把栈底元素挖出来，记在 num 里 (比如 1)
    // 此时栈里剩 [2, 3]
    int num = bottomOut(stack);
    
    // 2. 递归：把剩下的 [2, 3] 逆序
    // 这一步执行完后，栈里变成了 [3, 2] (3在顶)
    reverse(stack);
    
    // 3. 盖顶：把刚才挖出来的 1，盖在最上面
    // 栈变成了 [3, 2, 1] (1在顶)
    stack.push(num);
}
```

### 5. 【总结】

- **没有显式使用额外空间**：虽然没 `new` 数组或 `new` 栈，但实际上使用了 $O(N)$ 的**系统栈空间**（递归深度）。
- **执行顺序**：`bottomOut` 负责“下潜抓人再上浮”，`reverse` 负责“排兵布阵”。
- **核心思维**：当你想要处理栈底元素，但只能访问栈顶时，就用递归把栈顶元素暂存到系统栈里，等处理完下面了再放回来。



# 6. 用递归函数排序栈



## 代码

```java
import java.util.Stack;

public class Code06_SortStackWithRecursive {
    public static void sort(Stack<Integer> stack) {
        int deep = deep(stack);
        while (deep > 0) {
            int max = max(stack, deep);
            int k = times(stack, deep, max);
            down(stack, deep, max, k);
            deep -= k;
        }
    }

    public static int deep(Stack<Integer> stack) {
        if (stack.isEmpty()) {
            return 0;
        }

        int num = stack.pop();
        int deep = deep(stack) + 1;
        stack.push(num);
        return deep;
    }

    // 从栈当前的顶部开始，往下数deep层
    // 返回这deep层里的最大值
    public static int max(Stack<Integer> stack, int deep) {
        if (deep == 0) {
            return Integer.MIN_VALUE;
        }

        int num = stack.pop();
        int restMax = max(stack, deep - 1);
        int max = Math.max(num, restMax);
        stack.push(num);
        return max;
    }

    // 从栈当前的顶部开始，往下数deep层，已知最大值是max了
    // 返回，max出现了几次，不改变栈的数据状况
    public static int times(Stack<Integer> stack, int deep, int max) {
        if (deep == 0) {
            return 0;
        }

        int num = stack.pop();
        int restTimes = times(stack, deep - 1, max);
        int times = restTimes + (num == max ? 1 : 0);
        stack.push(num);
        return times;
    }

    // 从栈当前的顶部开始，往下数deep层，已知最大值是max，出现了k次
    // 请把这k个最大值沉底，剩下的数据状况不变
    public static void down(Stack<Integer> stack, int deep, int max, int k) {
        if (deep == 0) {
            for (int i = 0; i < k; i++) {
                stack.push(max);
            }
        }else {
            int num = stack.pop();
            down(stack, deep - 1, max, k);
            if (num != max) {
                stack.push(num);
            }
        }
    }

    public static Stack<Integer> randomStack(int n, int v) {
        Stack<Integer> ans = new Stack<Integer>();
        for (int i = 0; i < n; i++) {
            ans.add((int) (Math.random() * v));
        }
        return ans;
    }

    // 为了测试
    // 检测栈是不是从顶到底依次有序
    public static boolean isSorted(Stack<Integer> stack) {
        int step = Integer.MIN_VALUE;
        while (!stack.isEmpty()) {
            if (step > stack.peek()) {
                return false;
            }
            step = stack.pop();
        }
        return true;
    }

    // 为了测试
    public static void main(String[] args) {
        Stack<Integer> test = new Stack<Integer>();
        test.add(1);
        test.add(5);
        test.add(4);
        test.add(5);
        test.add(3);
        test.add(2);
        test.add(3);
        test.add(1);
        test.add(4);
        test.add(2);
        sort(test);
        while (!test.isEmpty()) {
            System.out.println(test.pop());
        }

        // 随机测试
        int N = 20;
        int V = 20;
        int testTimes = 20000;
        System.out.println("测试开始");
        for (int i = 0; i < testTimes; i++) {
            int n = (int) (Math.random() * N);
            Stack<Integer> stack = randomStack(n, V);
            sort(stack);
            if (!isSorted(stack)) {
                System.out.println("出错了!");
                break;
            }
        }
        System.out.println("测试结束");
    }
}
```



## 思路

这份代码是递归思维训练的终极挑战之一。它通过纯递归的方式实现了类似“冒泡排序”或“选择排序”的逻辑，且完全依赖**系统调用栈**来充当临时存储空间。

### 

### 1. 【一句话核心】

**“大海捞针再沉底”**：把栈看作一个竖着的数组。每次在未排序的范围（深度 `deep`）内找到最大值 `max`，利用递归把这个最大值“抓”出来，先铺在未排序区域的最底层，然后再把其余元素盖上去。如此反复，直到未排序区域消失。

### 2. 【核心变量与逻辑】

排序的整体策略是：**每次把未排序部分的最大值沉底。**

- **`deep` (深度)**: 当前未排序区域的元素个数。初始为全栈深度，随着最大值不断沉底，`deep` 逐渐减小。
- **`max` (最大值)**: 在 `deep` 范围内找到的最大值。
- **`k` (次数)**: 最大值 `max` 在 `deep` 范围内出现了几次。
- **核心动作 `down`**: 将 `deep` 范围内的 `k` 个 `max` 移动到这 `deep` 层元素的最底下。

### 3. 【四大金刚函数解析】

为了完成任务，我们需要四个递归函数互相配合：

1. **`deep(stack)`**:
   - **作用**: 数数。计算栈里有多少个元素。
   - **技巧**: `pop` 一个，`count+1`，递归，回来再 `push` 回去。这也是后续所有“不改变数据状况”函数的标准模板。
2. **`max(stack, deep)`**:
   - **作用**: 找大哥。在栈顶向下的 `deep` 层里找到最大值。
   - **逻辑**: 拿出栈顶 `num`，问剩下的 `deep-1` 层谁最大？两者取 `Max`。
3. **`times(stack, deep, max)`**:
   - **作用**: 数大哥。统计 `max` 出现了几次。
   - **逻辑**: 拿出栈顶 `num`，如果 `num == max` 则计数 +1，否则 +0，加上递归结果。
4. **`down(stack, deep, max, k)` (最核心、最难懂)**:
   - **作用**: **乾坤大挪移**。
   - **任务**: 在 `deep` 深度内，删除所有的 `max`，并将 `k` 个 `max` 压入这 `deep` 层的最底部。
   - **实现原理**:
     - **下潜阶段**: 一层层 `pop` 数据，保存在系统栈的局部变量中。
     - **触底阶段 (`deep == 0`)**: 说明到达了本次排序范围的“地板”。**在这里先 push `k` 个 `max` 进去**。
     - **上浮阶段**: 递归返回。检查刚才 `pop` 在手里的数 `num`。
       - 如果 `num == max`: **丢弃**（因为已经在触底阶段加过了）。
       - 如果 `num != max`: **压入栈**。

------

### 4. 【超详细图解：全过程推演】

假设栈从顶到底为：`[1, 3, 2]`。

目标：排序后从顶到底为 `[1, 2, 3]` (即栈底最大)。

#### 第一轮排序 (`deep` = 3)

1. **准备**:
   - `deep` = 3。
   - `max` = **3** (在 1, 3, 2 中最大)。
   - `k` = **1** (3 出现了一次)。
2. **执行 `down(stack, 3, 3, 1)`**:
   - **目标**: 把 3 沉到这 3 个元素的最底下。

Plaintext

```
[系统调用栈] (递归向下)                   [数据栈状态] (左边是顶)

1. down(deep=3)
   取出 num=1
   调用 down(deep=2)...                  栈: [3, 2]

    2. down(deep=2)
       取出 num=3 (是max!)
       调用 down(deep=1)...              栈: [2]

        3. down(deep=1)
           取出 num=2
           调用 down(deep=0)...          栈: [] (本次范围空了)

            4. down(deep=0) [Base Case]
               "触底了！开始铺地基"
               循环 k=1 次: push(max)
               push(3)                   栈: [3]
               return
            
        3. 回到 down(deep=1)
           手里的 num=2
           2 != max ? 是的
           push(2)                       栈: [2, 3]
           return

    2. 回到 down(deep=2)
       手里的 num=3
       3 != max ? 否 (它是max)
       "丢弃! 不push" (因为地基里已经有了)
       return                            栈: [2, 3]

1. 回到 down(deep=3)
   手里的 num=1
   1 != max ? 是的
   push(1)                               栈: [1, 2, 3]
   return
```

**第一轮结果**: 栈变成了 `[1, 2, 3]`。最大值 3 已经成功沉底。

**下一步**: `deep` 减去 `k` (1)，变成 2。

------

#### 第二轮排序 (`deep` = 2)

现在只看栈顶的 2 个元素 `[1, 2]` (虽然栈底还有个 3，但我们控制 deep 把它“隔离”了)。

1. **准备**:
   - `deep` = 2。
   - `max` = **2**。
   - `k` = **1**。
2. **执行 `down(stack, 2, 2, 1)`**:

Plaintext

```
[系统调用栈]                              [数据栈状态] (忽略最底下的3)

1. down(deep=2)
   取出 num=1
   调用 down(deep=1)...                  栈: [2] | 3

    2. down(deep=1)
       取出 num=2 (max)
       调用 down(deep=0)...              栈: [] | 3

            3. down(deep=0) [Base Case]
               push(max) -> push(2)      栈: [2] | 3
               return

    2. 回到 down(deep=1)
       手里的 num=2 (max)
       "丢弃"                            栈: [2] | 3
       return

1. 回到 down(deep=2)
   手里的 num=1
   push(1)                               栈: [1, 2] | 3
   return
```

**第二轮结果**: 栈变成了 `[1, 2, 3]`。

**下一步**: `deep` 减 1，变成 1。

------

#### 第三轮排序 (`deep` = 1)

1. **准备**: `max`=1, `k`=1。
2. **执行 `down`**:
   - 把 1 拿掉。
   - 触底 (`deep=0`)，push 1。
   - 回来，丢弃手里的 1。
3. **结果**: 栈还是 `[1, 2, 3]`。位置没变。
4. `deep` 变为 0，循环结束。

### 5. 【复杂度分析】

这是一次非常昂贵的炫技。

- **时间复杂度**: $O(N^2)$。
  - 每次循环 `deep` 减小 1 (最坏情况)。
  - 循环内部：`max`($O(N)$) + `times`($O(N)$) + `down`($O(N)$)。
  - 总共就是 $N \times 3N \approx O(N^2)$。
- **空间复杂度**: $O(N)$。
  - 虽然没有额外容器，但递归调用栈的深度最大为 $N$。

### 6. 【总结】

这段代码演示了如何利用**递归函数的调用栈**作为隐式的存储容器。

- `max`, `times`, `deep` 演示了如何**遍历**栈且复原。
- `down` 演示了如何**重构**栈（删除特定元素并在特定位置插入）。



# 7. 打印n层汉诺塔问题的最优移动轨迹

## 代码

```java
public class Code07_TowerOfHanoi {
    public static void hanoi(int n) {
        if (n > 0) {
            f(n, "左", "右", "中");
        }
    }

    public static void f(int i, String from, String to, String other) {
        if (i == 1) {
            System.out.println("移动圆盘 1 从 " + from + " 到 " + to);
        } else {
            f(i - 1, from, other, to);
            System.out.println("移动圆盘 " + i + " 从 " + from + " 到 " + to);
            f(i - 1, other, to, from);
        }
    }

    public static void main(String[] args) {
        int n = 3;
        hanoi(n);
    }
}
```



## 思路



### 1. 【一句话核心】

**“冰箱装大象”**：不要去想每一层具体怎么移，只把圆盘分为两部分——**“最底下那个(第N个)”** 和 **“上面那一坨(1~N-1个)”**。

核心三步走：**把“上面那一坨”移到辅助柱 -> 把“最底下那个”移到目标柱 -> 把“上面那一坨”移到目标柱**。

### 2. 【宏观思维图解】

假设我们要把 **N=3** 个圆盘，从 **左 (Start)** 移到 **右 (Target)**，中间是 **中 (Help)**。

不要去想第1个盘子怎么动，第2个怎么动。**只看整体！**

**步骤拆解 (ASCII 演示)：**

**初始状态**：

Plaintext

```
  |        |        |
 [1]       |        |
 [2]       |        |
 [3]       |        |
=====    =====    =====
 左(From)  中(Other) 右(To)
```

**Step 1: 递归黑盒 (把 1~2 移走)**

也就是代码中的 `f(i - 1, from, other, to)`。

把 `1~2` 看作一个整体，借助“右”，移到“中”。

Plaintext

```
  |        |        |
  |       [1]       |
  |       [2]       |
 [3]       |        |
=====    =====    =====
 左       中       右
```

**Step 2: 关键一步 (移动 N)**

也就是代码中的 `System.out.println`。

此时左边只剩最大的 `3`，中间没障碍，直接移到“右”。

Plaintext

```
  |        |        |
  |       [1]       |
  |       [2]      [3]
  |        |        |
=====    =====    =====
 左       中       右
```

**Step 3: 递归黑盒 (把 1~2 移回来)**

也就是代码中的 `f(i - 1, other, to, from)`。

把在“中”的那一坨 `1~2`，借助“左”，移到“右”盖在 `3` 上面。

Plaintext

```
  |        |        |
  |        |       [1]
  |        |       [2]
  |        |       [3]
=====    =====    =====
 左       中       右
```

### 3. 【代码逐行精读】

```java
// i: 当前要处理的盘子层数（也代表第i个盘子）
// from: 现在的源头在哪里
// to:   现在的目标是哪里
// other: 现在谁是辅助
public static void f(int i, String from, String to, String other) {
    // 【Base Case】
    // 只剩最上面的一个盘子了，不需要辅助，直接搬过去
    if (i == 1) {
        System.out.println("移动圆盘 1 从 " + from + " 到 " + to);
    } else {
        // 【第一步：移开路障】
        // 目标：把 i 上面的 (i-1) 层，从 from 移到 other。
        // 此时 to 变成了辅助位。
        f(i - 1, from, other, to);
        
        // 【第二步：移动主角】
        // 此时上面的路障都清空了，把 i 从 from 直接移到 to。
        System.out.println("移动圆盘 " + i + " 从 " + from + " 到 " + to);
        
        // 【第三步：归位】
        // 目标：把刚才暂存在 other 的 (i-1) 层，移到 to (盖在 i 上面)。
        // 此时 from 变成了辅助位。
        f(i - 1, other, to, from);
    }
}
```



### 4. 【参数轮转的艺术】

汉诺塔最绕的地方在于：**谁是起点，谁是终点，谁是辅助，在不断变化。**

| **动作**              | **函数调用**         | **解释**                                                     |
| --------------------- | -------------------- | ------------------------------------------------------------ |
| **整体任务**          | `f(N, 左, 右, 中)`   | 我要把 N 从左移到右，中帮忙。                                |
| **Step 1 (移走障碍)** | `f(N-1, 左, 中, 右)` | 这一步的目标变成了“中”。 所以 `to` 变成了“中”，`other` 变成了“右”。 |
| **Step 2 (主角移动)** | Print                | 物理移动第 N 个盘子。                                        |
| **Step 3 (障碍归位)** | `f(N-1, 中, 右, 左)` | 这一步的起点变成了“中”。 所以 `from` 变成了“中”，`other` 变成了“左”。 |

### 5. 【复杂度与规律】

- **移动次数**：$2^N - 1$ 次。
  - N=3, 次数 = 7。
  - N=10, 次数 = 1023。
- **时间复杂度**：$O(2^N)$。
- **空间复杂度**：$O(N)$ (递归栈的深度)。

### 6. 【复习闪卡】

1. **Q: 汉诺塔的递归终止条件是什么？**
   - A: 当 `i == 1` 时，直接移动，不递归。
2. **Q: 为什么把 `other` 传给第二个递归的 `to` 参数？**
   - A: 因为在第一步中，我们要把上面的一坨移到“辅助柱”暂存，所以此时“辅助柱”就是这一小步的“目标”。
3. **Q: 怎么打印出最优轨迹？**
   - A: 中序遍历的思想。左递归(移走上层) -> 打印自己(移到底层) -> 右递归(移回上层)。
