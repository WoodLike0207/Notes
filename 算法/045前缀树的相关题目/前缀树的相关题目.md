## 代码

```java
import java.util.Arrays;

public class Code01_CountConsistentKeys {
    public static int[] countConsistentKeys(int[][] b, int[][] a) {
        build();
        StringBuilder builder = new StringBuilder();

        for (int[] nums : a) {
            builder.setLength(0);
            for (int i = 1; i < nums.length; i++) {
                builder.append(String.valueOf(nums[i] - nums[i-1]) + "#");
            }
            insert(builder.toString());
        }

        int[] ans = new int[b.length];
        for (int i = 0; i < b.length; i++) {
            builder.setLength(0);
            int[] nums = b[i];

            for (int j = 1; j < nums.length; j++) {
                builder.append(String.valueOf(nums[j] - nums[j-1]) + "#");
            }

            ans[i] = count(builder.toString());
        }
        clear();
        return ans;
    }

    public static int MAXN = 2000001;
    public static int[][] tree = new int[MAXN][12];
    public static int[] pass = new int[MAXN];
    public static int cnt;
    public static void build() {
        cnt = 1;
    }

    public static int path(char cha) {
        if (cha == '#') {
            return 10;
        } else if (cha == '-') {
            return 11;
        }else {
            return cha - '0';
        }
    }

    public static void insert(String word) {
        int cur = 1;
        pass[cur]++;

        for (int i = 0; i < word.length(); i++) {
            int path = path(word.charAt(i));

            if (pass[tree[cur][path]] == 0) {
                tree[cur][path] = ++cnt;
            }

            cur = tree[cur][path];
            pass[cur]++;
        }
    }

    public static int count(String pre) {
        int cur = 1;
        for (int i = 0; i < pre.length(); i++) {
            int path = path(pre.charAt(i));

            if (pass[tree[cur][path]] == 0) {
                return 0;
            }

            cur = tree[cur][path];
        }

        return pass[cur];
    }

    public static void clear() {
        for (int i = 1; i <= cnt; i++) {
            Arrays.fill(tree[i], 0);
            pass[i] = 0;
        }
    }
}
```



## 思路

这是 **NowCoder 牛牛的接头密匙** 问题的解法。

这道题巧妙地将“数组子序列匹配”问题转化为了**差分数组** + **前缀树（Trie）** 的前缀统计问题。



### 1. 【一句话核心】

**“差分定形状，前缀查数量”**：先将原数组转化为**差分数组**（只看相邻数字的变化量），再把差分数组转成**字符串**存入前缀树，利用 `pass` 计数快速统计有多少个长数组（`a`）包含短数组（`b`）作为前缀。

### 2. 【算法技巧操作】

- **差分转化 (Difference Array)**：
  - 题目定义的“一致”其实就是**相对变化趋势一致**。
  - 例如 `[3, 6, 50]` 的变化是 `+3, +44`。
  - 我们不关心具体数字，只关心 `nums[i] - nums[i-1]`。
- **序列化技巧 (Serialization)**：
  - 差分后的数字可能是负数（如 `-40`），也可能是多位数（如 `44`）。
  - 为了存入 Trie，必须把数字变成字符序列。
  - **分隔符 `#`**：必须加！否则 `1, 2` 变成 `"12"`，和 `12` 变成 `"12"` 就混淆了。
  - **负号 `-`**：作为一个普通字符处理。
- **字符映射 (Path Mapping)**：
  - Trie 的分支通常是 `0-25`。这里字符集包括 `0-9`、`-`、`#`。
  - 代码中 `path(char)` 函数将这 12 种字符映射到了 `0-11` 的数组下标。

### 3. 【图解原理】

假设我们有以下输入：

- **数组 A (字典库)**:
  1. `[1, 3, 2]` -> 差分: `+2, -1` -> 字符串: `"2#-1#"`
  2. `[5, 7, 9]` -> 差分: `+2, +2` -> 字符串: `"2#2#"`
- **数组 B (查询)**:
  1. `[8, 10]` -> 差分: `+2` -> 字符串: `"2#"`

**流程：**

1. 把 A 中的所有序列插入 Trie，沿途增加 `pass` 计数。
2. 用 B 的序列在 Trie 中查找，走到终点时，当前的 `pass` 值就是答案。

![image-20260131233411360](%E5%89%8D%E7%BC%80%E6%A0%91%E7%9A%84%E7%9B%B8%E5%85%B3%E9%A2%98%E7%9B%AE.assets/image-20260131233411360.png)

**图解说明：**

- **左侧 (Insert A)**：
  - 插入 `"2#-1#"`：路径上的节点 `pass` 都 +1。
  - 插入 `"2#2#"`：路径 `"2#"` 部分复用，`pass` 累加变成 2；后面分叉。
- **右侧 (Query B)**：
  - 查询 `"2#"`。
  - 沿着 '2' -> '#' 走。
  - 走到 '#' 节点，发现 `pass` 是 2。
  - **含义**：有两个数组 A 的开头差分是 `+2`，所以答案是 2。

### 4. 【代码逐行精读】

**序列化与建树 (Insert)**

```java
// 遍历长数组集合 a，把它们作为“字典”插入树中
for (int[] nums : a) {
    builder.setLength(0); // 清空 StringBuilder
    // 从 1 开始遍历，计算 nums[i] - nums[i-1]
    for (int i = 1; i < nums.length; i++) {
        // 【关键】转成字符串，并加上 '#' 分隔符
        // 比如 3, 6, 50 -> "3#44#"
        builder.append(String.valueOf(nums[i] - nums[i - 1]) + "#");
    }
    insert(builder.toString()); // 插入 Trie
}
```

**字符映射 (Path)**

```java
// 把字符映射为 0~11 的索引，供 tree[cur][path] 使用
public static int path(char cha) {
    if (cha == '#') {
        return 10; // '#' 映射为 10
    } else if (cha == '-') {
        return 11; // '-' 映射为 11
    } else {
        return cha - '0'; // '0'-'9' 映射为 0-9
    }
}
```

**统计查询 (Count)**

```java
public static int count(String pre) {
    int cur = 1;
    for (int i = 0, path; i < pre.length(); i++) {
        path = path(pre.charAt(i));
        // 如果路断了，说明没有匹配的前缀，直接返回 0
        if (tree[cur][path] == 0) {
            return 0;
        }
        cur = tree[cur][path];
    }
    // 【核心】返回当前节点的 pass 值
    // 代表有多少个 a 数组，以当前的 pre 作为差分前缀
    return pass[cur];
}
```

### 5. 【死记硬背点 / 易错点】

1. **必须有分隔符**：做数字转字符串的 Trie 题目，**一定**要在每个数字后面加特殊符号（如 `#`），否则多位数会混淆（`12` vs `1,2`）。
2. **树的大小 (MAXN)**：
   - 这里的 `MAXN` 不是数组个数，而是**所有差分字符串的总字符长度**。
   - 如果是 `10^5` 个数组，每个数字都很大（如 `-12345#` 占7个字符），`MAXN` 需要开得足够大（题目给的 200w 是安全的）。
3. **谁查谁**：题目问“b 是 a 的一致密匙”，意味着 b 是 a 的前缀。所以**把 a (长) 插入树，用 b (短) 去查**。反过来就变成了查“a 是 b 的前缀”，逻辑就错了。

### 6. 【复习闪卡】

1. **Q: 为什么要把数字序列转成差分数组？**
   - A: 因为题目定义的一致性是 `b[i+1]-b[i] == a[i+1]-a[i]`，即**相对变化量**相同，差分数组能抹去绝对数值的差异，只保留形状。
2. **Q: 为什么 Trie 的节点路径需要映射 '-' 和 '#'？**
   - A: 因为差分值可能是负数，且需要分隔符区分多位数。这两个符号也是路径的一部分，需要分配独立的索引（10 和 11）。
3. **Q: `count` 函数最后返回 `pass[cur]` 而不是 `end[cur]`，为什么？**
   - A: 因为我们求的是**前缀匹配**。只要 b 是 a 的前缀就算一致，不需要 a 在这里结束。`pass` 记录了有多少个样本经过了当前路径。





# 2. 数组中两个数的最大异或值

![image-20260131233638751](%E5%89%8D%E7%BC%80%E6%A0%91%E7%9A%84%E7%9B%B8%E5%85%B3%E9%A2%98%E7%9B%AE.assets/image-20260131233638751.png)

测试链接 : https://leetcode.cn/problems/maximum-xor-of-two-numbers-in-an-array/

<br>

## 代码

```java
import java.util.Map;

public class Code02_TwoNumbersMaximumXor {
    public static int findMaximumXOR(int[] nums) {
        build(nums);
        int ans = 0;
        for (int num : nums) {
            ans = Math.max(ans, maxXor(num));
        }
        clear();
        return ans;
    }

    public static int MAXN = 3000001;

    public static int[][] tree = new int[MAXN][2];

    // 前缀树目前使用了多少空间
    public static int cnt;

    // 数字只需要从哪一位开始考虑
    public static int high;

    public static void build(int[] nums) {
        cnt = 1;
        int max = Integer.MIN_VALUE;
        for (int num : nums) {
            max = Math.max(max, num);
        }

        high = 31 - Integer.numberOfLeadingZeros(max);
        for (int num : nums) {
            insert(num);
        }
    }

    private static void insert(int num) {
        int cur = 1;
        for (int i = high; i >= 0; i--) {
            int path = (num >> i) & 1;
            if (tree[cur][path] == 0) {
                tree[cur][path] = ++cnt;
            }
            cur = tree[cur][path];
        }
    }

    public static int maxXor(int num) {
        int ans = 0;
        int cur = 1;

        for (int i = high, status, want; i >= 0; i--) {
            status = (num >> i) & 1;
            want = status ^ 1;

            if (tree[cur][want] == 0) {
                want ^= 1;
            }

            ans |= (status ^ want)<< i;
            cur = tree[cur][want];
        }
        return ans;
    }

    public static void clear() {
        for (int i = 1; i <= cnt; i++) {
            tree[i][0] = tree[i][1] = 0;
        }
    }
}
```



## 思路

### 1. 【核心解题思路】

**“前缀树导航 + 高位贪心”**

* **为什么用前缀树？** 我们需要在一个集合中快速判断“是否存在某个前缀”。前缀树能把所有数字的二进制形式存起来，方便按位查找。
* **什么是贪心？**
* 异或的性质是 **相同得0，不同得1**。
* 为了让结果最大，我们希望结果里的 `1` 尽可能的出现在**高位**。
* **策略**：对于每个数字，从最高位开始，每一步都尽量走与自己当前位**相反**的路（想把 `0` 变 `1`）。只有当相反的路走不通时，才被迫走相同的路。



---

### 2. 【图解全过程：从建树到查询】

我们使用测试用例：`nums = [3, 10, 5]`。
为了方便展示，我们只看 **4位二进制**（实际题目是31位，逻辑一样）。

* **3**: `0 0 1 1`
* **10**: `1 0 1 0`
* **5**: `0 1 0 1`

#### **第一阶段：构建前缀树 (Building the Trie)**

我们要把这三个数种到树上。**0往左走，1往右走**。

**步骤 1：插入 3 (`0011`)**

```text
(Root)
  | 0 (Bit 3)
 (A)
  | 0 (Bit 2)
 (B)
   \ 1 (Bit 1)
   (C)
     \ 1 (Bit 0)
     (D) <--- 数字3结束

```

**步骤 2：插入 10 (`1010`)**
从 Root 开始，第一步是 `1`，所以不能复用 `(A)`，要新建分支。

```text
       (Root)
      /      \
(Bit3)0      1(Bit3) <--- 分叉点
     /        \
   (A)        (E)
    |0         |0 (Bit 2)
   (B)        (F)
     \1         \1 (Bit 1)
     (C)        (G)
       \1         \1 (Bit 0)
       (D)        (H) <--- 数字10结束

```

**步骤 3：插入 5 (`0101`)**

* Bit 3 是 `0` -> 走左边（复用 Root->A 的路）
* Bit 2 是 `1` -> A 的左边是 0，没路去 1，所以在 A 处新建右分支。

```text
           (Root)
          /      \
  (Bit3) 0/        \1 (Bit3)
         v          v
        (A)        (E) <--- 通往10
  (Bit2)0/ \1(Bit2) |0
        v   v       v
       (B) (I)     (F)
        \1  |0      \1
         v  v        v
        (C) (J)     (G)
         \1  \1       \0 (注意:10的最后一位是0)
          v   v        v
         (D) (K)      (H)
        (3)  (5)      (10)

```

**建树总结**：此时树里包含了所有潜在的“匹配对象”。

---

#### **第二阶段：贪心查询 (Greedy Search)**

现在我们要算 `findMaximumXOR`。我们需要遍历数组里的每个数，去树里找它的“最佳伴侣”。
**以数字 3 (`0011`) 为例，看看它是怎么找到最大异或值的。**

* **当前手里拿的数字**：`num = 3` (`0 0 1 1`)
* **目标**：每一位都尽量找**相反**的数字。

**Step 1: 处理 Bit 3 (最高位)**

* **我的位**：`0`
* **我的梦想 (`want`)**：找 `1` (因为 `0^1=1`)
* **前缀树导航**：站在 Root，有去往 `1` 的路吗？
* *看图*：有！(通往节点 E)。


* **决策**：**梦想成真！** 往右走去节点 E。
* **当前收益**：这一位异或得 1。`ans` 第3位设为 1 (8)。

**Step 2: 处理 Bit 2**

* **我的位**：`0`
* **我的梦想 (`want`)**：找 `1`
* **前缀树导航**：站在节点 E，有去往 `1` 的路吗？
* *看图*：节点 E 只有去往 `0` (节点 F) 的路。


* **决策**：**被迫妥协**。只能走去节点 F。
* **当前收益**：这一位异或得 0 (`0^0`)。`ans` 第2位是 0。

**Step 3: 处理 Bit 1**

* **我的位**：`1`
* **我的梦想 (`want`)**：找 `0`
* **前缀树导航**：站在节点 F，有去往 `0` 的路吗？
* *看图*：节点 F 只有去往 `1` (节点 G) 的路。


* **决策**：**被迫妥协**。只能走去节点 G。
* **当前收益**：这一位异或得 0 (`1^1`)。`ans` 第1位是 0。

**Step 4: 处理 Bit 0 (最低位)**

* **我的位**：`1`
* **我的梦想 (`want`)**：找 `0`
* **前缀树导航**：站在节点 G，有去往 `0` 的路吗？
* *看图*：有！(去往节点 H)。


* **决策**：**梦想成真！** 往左走去节点 H。
* **当前收益**：这一位异或得 1。`ans` 第0位设为 1 (1)。

**最终计算**：
`ans = 8 + 0 + 0 + 1 = 9`。
这意味着 `3 ^ 10 = 9`。这比 `3 ^ 5 (6)` 要大。
程序会对 10 和 5 也做同样的过程，最后取最大值。

---

### 3. 【代码详细解读】

```java
// 核心部分：寻找 num 的最佳匹配
public static int maxXor(int num) {
    int ans = 0;
    int cur = 1; // 从 Root 出发
    
    // high 是最高有效位（比如31或30...）
    // 从高位向低位遍历，体现"高位贪心"
    for (int i = high, status, want; i >= 0; i--) {
        // status: 我当前这一位是几 (0 或 1)
        status = (num >> i) & 1;
        
        // want: 我最想要什么？当然是相反的！
        // status ^ 1 相当于取反
        want = status ^ 1;
        
        // 【关键判断】树上有没有我想要的那条路？
        if (tree[cur][want] == 0) {
            // 坏消息：没有想要的路。
            // 只能走那条"不想要"的路（也就是和 status 相同的路）
            want ^= 1; // 此时 want 变回了 status
        }
        
        // 【计算收益】
        // 如果刚才走的是理想的路，status 和 want 是相反的 -> status ^ want = 1
        // 如果刚才被迫走了相同的路，status 和 want 是相同的 -> status ^ want = 0
        // 将这个 1 或 0 移位到正确的位置，加到结果里
        ans |= (status ^ want) << i;
        
        // 迈出这一步，走到下一个节点
        cur = tree[cur][want];
    }
    return ans;
}

```

### 4. 【关键细节总结】

1. **High 的计算**：
* 代码里 `high = 31 - Integer.numberOfLeadingZeros(max)` 是为了**剪枝**。
* 如果数组里最大值只有 10 (`1010`)，那前面的 28 个 `0` 都是废话。我们只需要从第 3 位开始建树和查询，能省大量时间。


2. **want ^= 1 的含义**：
* 这是代码中最精妙的一行。
* 本来 `want` 是我的“梦想”。
* `if (tree[cur][want] == 0)` 发现“梦想之路”不通。
* `want ^= 1` 表示把“梦想”修改为“现实”，强行改道，避免死胡同。


3. **位运算优先级**：
* `ans |= (status ^ want) << i;`
* 这里利用了位运算的特性，一次性完成了“判断是否得分”和“累加分数”两个动作。
