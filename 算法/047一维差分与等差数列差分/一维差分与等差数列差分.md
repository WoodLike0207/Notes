# 1. 航班预订统计

测试链接 : https://leetcode.cn/problems/corporate-flight-bookings/



## 代码

```java
public class Code01_CorporateFlightBookings {
    public int[] corpFlightBookings(int[][] bookings, int n) {
        int[] cnt = new int[n + 2];

        for (int[] book : bookings) {
            cnt[book[0]] += book[2];
            cnt[book[1] + 1] -= book[2];
        }

        for (int i = 1; i <cnt.length ; i++) {
            cnt[i] += cnt[i-1];
        }

        int[] ans = new int[n];
        for (int i = 0; i < n; i++) {
            ans[i] = cnt[i + 1];
        }

        return ans;
    }
}
```



## 思路

这道题是 **一维差分 (Difference Array)** 的入门模板题。只要遇到 **“对某个区间范围内的所有数进行统一加减”** 的操作，必须立刻想到差分数组。



### 1. 【一句话核心】

**“掐头去尾”**：不需要真的去遍历区间修改每一个数。只需要在区间的**起始位置**加上数值，在区间的**结束位置+1** 减去数值，最后求一次**前缀和**，就能还原出最终结果。

### 2. 【差分数组详解】

#### **为什么要用差分？**

假设有一个全为 0 的数组，我们要把下标 `[2, 5]` 之间的每个数都 `+10`。

- **暴力法**：遍历下标 2 到 5，一个个加。复杂度 $O(N)$。如果有 $M$ 次操作，总复杂度 $O(M \times N)$。**太慢了！**
- **差分法**：只修改两个点，复杂度 $O(1)$。如果有 $M$ 次操作，总复杂度 $O(M)$。**极快！**

#### **操作原理**

差分数组 `diff` 是原数组 `nums` 的**逆运算**。

- **性质**：`diff` 数组的**前缀和**就是 `nums` 数组（即 `nums[i] = diff[0] + ... + diff[i]`）。

- **区间修改公式**：

  如果要让区间 `[L, R]` 增加 `V`：

  1. **`diff[L] += V`**：表示从 `L` 开始，后面的数相对于前一个数“抬高”了 `V`。
  2. **`diff[R + 1] -= V`**：表示从 `R + 1` 开始，把刚才抬高的 `V` “抵消”掉，恢复原状（因为区间修改只到 `R` 结束）。

### 3. 【图解原理】

假设航班数 $N=5$。

操作：在航班 `[2, 4]` 上增加 10 个座位。

**详细推演：**

1. **初始状态**：`cnt` (差分数组) 全为 0。

   Plaintext

   ```
   Idx: 1  2  3  4  5  6
   Val: 0  0  0  0  0  0
   ```

2. **执行操作 `[2, 4, 10]`**：

   - 在起点 `2` 加上 10：`cnt[2] += 10`
   - 在终点+1 `5` 减去 10：`cnt[5] -= 10`

   Plaintext

   ```
   Idx: 1   2   3   4   5    6
   Val: 0  +10  0   0  -10   0
   ```

   *物理含义：从2号开始水平面升高10米，一直平铺过去，直到5号开始水平面降低10米（回到原位）。*

3. **还原结果 (求前缀和)**：

   遍历数组，`cnt[i] += cnt[i-1]`。

   - `i=1`: 0

   - `i=2`: 0 + 10 = **10**

   - `i=3`: 10 + 0 = **10**

   - `i=4`: 10 + 0 = **10**

   - `i=5`: 10 + (-10) = **0**

   - `i=6`: 0 + 0 = 0

     **最终结果**：`[0, 10, 10, 10, 0, 0]`。

     可以看到，区间 `[2, 4]` 成功都变成了 10。

### 4. 【代码逐行精读】

```java
public static int[] corpFlightBookings(int[][] bookings, int n) {
    // 【技巧】为什么要 n + 2 ?
    // 1. 题目航班是从 1 开始编号的，为了下标对应方便，我们不用 0 号位置。
    // 2. 差分操作需要访问 cnt[last + 1]。如果 last 是 n，我们需要访问 n+1。
    // 所以数组长度至少要 n + 2 (下标 0 到 n+1)。
    int[] cnt = new int[n + 2];
    
    // 1. 差分设置阶段 (处理每一条预订)
    for (int[] book : bookings) {
        // book[0] 是 start, book[1] 是 end, book[2] 是 seats
        
        // "左边加"：从起点开始生效
        cnt[book[0]] += book[2]; 
        
        // "右边加一减"：从终点的下一位开始失效
        cnt[book[1] + 1] -= book[2];
    }
    
    // 2. 前缀和还原阶段 (加工)
    // 此时 cnt 变成了题目要求的"每个航班的座位总数"
    for (int i = 1; i < cnt.length; i++) {
        cnt[i] += cnt[i - 1];
    }
    
    // 3. 结果提取阶段
    // 题目要求返回长度为 n 的数组
    int[] ans = new int[n];
    for (int i = 0; i < n; i++) {
        // 我们的有效数据是从 cnt[1] 开始的
        ans[i] = cnt[i + 1];
    }
    return ans;
}
```

### 5. 【死记硬背点 / 易错点】

1. **数组越界**：差分最容易出的 Bug 就是 `R + 1` 越界。如果题目给的范围是 `1~N`，差分数组最好开 `N + 2` 的大小，这样访问 `N + 1` 绝对安全。
2. **核心口诀**：**“左加右减”**（左端点加，右端点+1 减）。
3. **还原时机**：所有的加减操作做完之后，**只做一次**前缀和还原。

### 6. 【复习闪卡】

1. **Q: 什么时候使用差分数组？**
   - A: 当需要对数组的**某个区间**进行**频繁的加减**操作，且最后只需要一次查询结果时。
2. **Q: 差分操作中 `cnt[R+1] -= val` 的作用是什么？**
   - A: 抵消影响。因为前缀和会把 `cnt[L]` 的增量一直累加下去，必须在区间结束的下一个位置减去同样的值，才能让区间之外的部分不受影响。
3. **Q: 差分和前缀和的关系？**
   - A: 互为逆运算。差分数组的前缀和 = 原数组；原数组的差分 = 差分数组。



# 2. 等差数列差分

![image-20260206231245740](%E4%B8%80%E7%BB%B4%E5%B7%AE%E5%88%86%E4%B8%8E%E7%AD%89%E5%B7%AE%E6%95%B0%E5%88%97%E5%B7%AE%E5%88%86.assets/image-20260206231245740.png)

### 核心概念：二阶差分

普通的差分数组（一阶差分）用于在区间 `[l, r]` 上加上一个 **常数**。

而这里的代码用于在区间 `[l, r]` 上加上一个 **等差数列**。

因为等差数列的“差分”（相邻两数的差）是一个常数，所以如果我们对“差分数组”再做一次差分（即二阶差分），就能把操作转化为修改几个特定的点。

### 代码解析

1. **`set` 函数（修改操作）**：

   这个函数的作用是在区间 `[l, r]` 上加上一个首项为 `s` (start)，末项为 `e` (end)，公差为 `d` (difference) 的等差数列。

   它修改了二阶差分数组 `arr` 的四个位置：

   - `arr[l] += s;`
   - `arr[l + 1] += d - s;`
   - `arr[r + 1] -= d + e;`
   - `arr[r + 2] += e;`

2. **`build` 函数（还原操作）**：

   - 第一个 `for` 循环：做一次前缀和，将 **二阶差分数组** 还原为 **一阶差分数组**。
   - 第二个 `for` 循环：再做一次前缀和，将 **一阶差分数组** 还原为 **原数组**（真实数值）。

------

### 图解举例说明

**场景**：

假设我们有一个长度为 10 的全 0 数组。

我们要执行一个操作：**在区间 `[2, 4]` 加上一个等差数列 `1, 3, 5`**。

**参数分析**：

- `l = 2`, `r = 4` (区间)
- `s = 1` (首项)
- `e = 5` (末项)
- `d = 2` (公差, 因为 3-1=2, 5-3=2)

#### 第一步：执行 `set(2, 4, 1, 5, 2)`

根据代码公式，我们修改 `arr` 数组（初始全为0）：

1. `arr[l] += s`  => `arr[2] += 1`
2. `arr[l + 1] += d - s` => `arr[3] += 2 - 1` (即 +1)
3. `arr[r + 1] -= d + e` => `arr[5] -= 2 + 5` (即 -7)
4. `arr[r + 2] += e` => `arr[6] += 5`

此时，**二阶差分数组 `arr`** 的状态是：

```java
数值: 0  1  1  0 -7  5  0 ...
索引: 1  2  3  4  5  6  7 ...
```

#### 第二步：执行 `build` 中的第一个循环（还原一阶差分）

做一次前缀和 (`arr[i] += arr[i-1]`)：

- i=1: 0
- i=2: 0 + 1 = **1** (这是首项 s)
- i=3: 1 + 1 = **2** (这是公差 d)
- i=4: 2 + 0 = **2** (中间保持公差 d)
- i=5: 2 + (-7) = **-5** (这是 -e，用来抵消原来的数值)
- i=6: -5 + 5 = **0** (归零)

此时，数组变成了 **一阶差分数组**：

```java
数值: 0  1  2  2 -5  0  0 ...
索引: 1  2  3  4  5  6  7 ...
```

*含义解读：在索引2加了1，在索引3比前一位多加了2，在索引4比前一位多加了2...*

#### 第三步：执行 `build` 中的第二个循环（还原原数组）

再做一次前缀和 (`arr[i] += arr[i-1]`)：

- i=1: 0
- i=2: 0 + 1 = **1**
- i=3: 1 + 2 = **3**
- i=4: 3 + 2 = **5**
- i=5: 5 + (-5) = **0**
- i=6: 0 + 0 = 0

此时，数组变成了 **最终结果**：

```java
数值: 0  1  3  5  0  0  0 ...
索引: 1  2  3  4  5  6  7 ...
```

**看！区间 `[2, 4]` 成功变成了 `1, 3, 5`，而其他位置依然是 0。**

------

### 为什么要这么写？（数学推导简述）

如果你想知道那 4 行代码是怎么推出来的，可以看这个逻辑：

我们希望 **一阶差分数组(D1)** 在区间内发生什么变化？

- 在 `l` 处：数值突然增加了 `s`。
- 在 `l+1` 到 `r` 处：因为是等差数列，每一项都比前一项多 `d`，所以差分数组的值应该维持在 `d`。
- 在 `r+1` 处：数列结束了，原来的数值是 `e`，下一项变回 0，所以相当于骤降了 `e`。

所以我们需要构建的 **一阶差分数组(D1)** 应该是这样的形状：

```
... 0, s, d, d, ..., d, -e, 0 ...
```

为了得到上面这个 `D1`，我们需要对它再求差分（即 **二阶差分 D2**），也就是计算 `D1` 相邻元素的差：

1. `l` 位置：由 0 变为 `s` -> 变化量是 `+s`。
   - 代码对应：`arr[l] += s`
2. `l+1` 位置：由 `s` 变为 `d` -> 变化量是 `d - s`。
   - 代码对应：`arr[l+1] += d - s`
3. `l+2` 到 `r` 位置：由 `d` 变为 `d` -> 变化量是 `0` (无需操作)。
4. `r+1` 位置：由 `d` 变为 `-e` -> 变化量是 `-e - d` (即 `-(d+e)`)。
   - 代码对应：`arr[r+1] -= d + e`
5. `r+2` 位置：由 `-e` 变为 `0` -> 变化量是 `0 - (-e) = +e`。
   - 代码对应：`arr[r+2] += e`

这就是这四行代码的完美由来。



# 3. 等差数列差分模板题

测试链接 : https://www.luogu.com.cn/problem/P4231



```java
import java.io.*;

public class Code02_ArithmeticSequenceDifference {
    public static int MAXN = 10000005;

    public static long[] arr = new long[MAXN];

    public static int n, m;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StreamTokenizer in = new StreamTokenizer(br);
        PrintWriter out = new PrintWriter(new OutputStreamWriter(System.out));
        while (in.nextToken() != StreamTokenizer.TT_EOF) {
            n = (int) in.nval;
            in.nextToken();
            m = (int) in.nval;
            for (int i = 0, l, r, s, e; i < m; i++) {
                in.nextToken(); l = (int) in.nval;
                in.nextToken(); r = (int) in.nval;
                in.nextToken(); s = (int) in.nval;
                in.nextToken(); e = (int) in.nval;
                set(l, r, s, e, (e - s) / (r - l));
            }
            build();
            long max = 0, xor = 0;
            for (int i = 1; i <= n; i++) {
                max = Math.max(max, arr[i]);
                xor ^= arr[i];
            }
            out.println(xor + " " + max);
        }
        out.flush();
        out.close();
        br.close();
    }

    public static void set(int l, int r, int s, int e, int d) {
        arr[l] += s;
        arr[l+1] += d-s;
        arr[r+1] -= d+e;
        arr[r+2] += e;
    }

    public static void build() {
        for (int i = 1; i <= n; i++) {
            arr[i] += arr[i-1];
        }

        for (int i = 1; i <= n; i++) {
            arr[i] += arr[i-1];
        }
    }
}
```
