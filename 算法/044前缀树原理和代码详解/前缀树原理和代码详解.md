# 1. 前缀树的原理





### 1. 【一句话核心】

**“路是字符，点是数据”**：把字符串拆成一个个字符，挂在一棵多叉树上。**公共前缀共用同一条路径**，只有字符不同时才分叉。节点不存字符，字符存在“树枝”（边）上。

### 2. 【核心概念：Pass 与 End】

在左神的体系中，为了支持更强大的查询功能（比如“以某字符串为前缀的单词有几个”），我们需要在**节点（Node）**上挂载两个关键数据：

- **`pass` (经过次数)**：有多少个单词在插入时，**路过**了这个节点。
  - *含义*：代表有多少个字符串以“从根节点到当前节点”的路径作为**前缀**。
- **`end` (结尾次数)**：有多少个单词以当前节点作为**终点**。
  - *含义*：代表这个具体的字符串被加入了多少次。

### 3. 【图解原理：从零构建前缀树】

假设我们要依次插入三个字符串：**"abc"**, **"abd"**, **"bce"**。

#### **阶段一：初始状态**

只有一颗**根节点 (Root)**。

- Root 的 `pass` 是 0（或者认为是总单词数），`end` 是 0。
- Root 有通往 'a'~'z' 的 26 条路（暂时都是空的）。

```java
  (Root)
[p=0, e=0]
```

#### **阶段二：插入 "abc"**

1. **'a'**：从 Root 出发，发现没路，新建节点 A。A 的 `pass=1`。
2. **'b'**：从 A 出发，没路，新建节点 B。B 的 `pass=1`。
3. **'c'**：从 B 出发，没路，新建节点 C。C 的 `pass=1`。
4. **结束**：单词结束了，节点 C 的 `end` 变成 1。

```java
       (Root)
      [p=1, e=0]
         | 'a' (新建)
         v
       (Node A)
      [p=1, e=0]
         | 'b' (新建)
         v
       (Node B)
      [p=1, e=0]
         | 'c' (新建)
         v
       (Node C)
      [p=1, e=1]  <-- end=1 说明 "abc" 存进来了
```

#### **阶段三：插入 "abd" (复用的艺术)**

1. **'a'**：从 Root 出发，**发现有去往 'a' 的路了！**
   - 直接复用 Node A。
   - 让 Node A 的 `pass` + 1 （变成 2）。
2. **'b'**：从 A 出发，**发现有去往 'b' 的路了！**
   - 直接复用 Node B。
   - 让 Node B 的 `pass` + 1 （变成 2）。
3. **'d'**：从 B 出发，**发现没有去往 'd' 的路**（只有去 'c' 的）。
   - 新建节点 D。
   - D 的 `pass=1`, `end=1`。

```java
       (Root)
      [p=2, e=0]
         | 'a' (复用，p++)
         v
       (Node A)
      [p=2, e=0]
         | 'b' (复用，p++)
         v
       (Node B)
      [p=2, e=0]  <-- 也就是前缀 "ab" 出现了2次
      /      \
 'c'/          \ 'd' (分叉，新建)
   v            v
(Node C)      (Node D)
[p=1, e=1]    [p=1, e=1]
("abc")       ("abd")
```

#### **阶段四：插入 "bce" (另起炉灶)**

1. **'b'**：从 Root 出发，**Root 只有去 'a' 的路，没有去 'b' 的路**（注意：之前的 'b' 是在 Node A 下面，不是 Root 下面）。
   - 所以在 Root 下面新建一条去 'b' 的路，连接到新节点 E。
2. ...后续依次建立节点。

```java
             (Root)
            [p=3, e=0]
           /          \
      'a' /            \ 'b' (新建分支)
         v              v
     (Node A)        (Node E)
    [p=2, e=0]      [p=1, e=0]
       |                |
   'b' |            'c' |
       v                v
     (Node B)        (Node F)
    [p=2, e=0]      [p=1, e=0]
    /      \            |
'c'/        \'d'    'e' |
  v          v          v
(Node C)   (Node D)   (Node G)
[p=1,e=1]  [p=1,e=1]  [p=1,e=1]
```

### 4. 【查询原理】

基于上面建立好的树，我们来看看它怎么回答查询：

1. **查 "abc" 这个单词插入过几次？**
   - 从 Root 走 `a` -> `b` -> `c`。
   - 如果不通，返回 0。
   - 如果通了，看最后到达的节点 C 的 **`end`** 值。
   - 答案：1 次。
2. **查以 "ab" 为前缀的单词有几个？**
   - 从 Root 走 `a` -> `b`。
   - 到达节点 B。
   - 看节点 B 的 **`pass`** 值。
   - 答案：2 个 (分别来自 "abc" 和 "abd")。

### 5. 【优缺点总结】

- **优点（快）**：
  - 查询速度只和**单词长度**有关，和字典里有多少个单词无关！
  - 比如查 "hello"，不管字典里有 100 个词还是 1 亿个词，它只走 5 步。
- **缺点（费）**：
  - **费空间**。如果单词之间没有公共前缀（比如 "a", "b", "c", "d"...），树会非常宽，产生大量节点。
  - 这也是为什么说它“和字符种类有关”，如果字符集很大（比如汉字），每个节点下面的路就太多了。



# 2. 类描述方式实现前缀树

```java
public class Code01_TrieTree {
    class Trie{
        class TrieNode {
            int pass;
            int end;
            TrieNode[] nexts;

            TrieNode() {
                pass = 0;
                end = 0;
                nexts = new TrieNode[26];
            }
        }

        private TrieNode root;

        public Trie() {
            root = new TrieNode();
        }

        public void insert(String word) {
            TrieNode node = root;
            node.pass++;

            for (int i = 0; i < word.length(); i++) {
                int path = word.charAt(i) - 'a';

                if (node.nexts[path] == null) {
                    node.nexts[path] = new TrieNode();
                }

                node = node.nexts[path];
                node.pass++;
            }

            node.end++;
        }

        public int search(String word) {
            TrieNode node = root;

            for (int i = 0; i < word.length(); i++) {
                int path = word.charAt(i) - 'a';

                if (node.nexts[path] == null) {
                    return 0;
                }

                node = node.nexts[path];
            }

            return node.end;
        }

        public int prefixNumber(String prefix) {
            TrieNode node = root;

            for (int i = 0; i < prefix.length(); i++) {
                int path = prefix.charAt(i) - 'a';

                if (node.nexts[path] == null) {
                    return 0;
                }

                node = node.nexts[path];
            }

            return node.pass;
        }

        public void delete(String word) {
            if (search(word) > 0) {
                TrieNode node = root;
                node.pass--;

                for (int i = 0; i < word.length(); i++) {
                    int path = word.charAt(i) - 'a';

                    if (--node.nexts[path].pass == 0) {
                        node.nexts[path] = null;
                        return;
                    }

                    node = node.nexts[path];
                }

                node.end--;
            }
        }
    }

    class Trie2{
        class TrieNode {
            int pass;
            int end;
            Map<Integer, TrieNode> nexts;

            TrieNode() {
                pass = 0;
                end = 0;
                nexts = new HashMap<>();
            }
        }

        private TrieNode root;
        public Trie2(){
            root = new TrieNode();
        }

        public void insert(String word) {
            TrieNode node = root;
            node.pass++;

            for (int i = 0; i < word.length(); i++) {
                int path = word.charAt(i) ;

                if (!node.nexts.containsKey(path)) {
                    node.nexts.put(path, new TrieNode());
                }

                node = node.nexts.get(path);
                node.pass++;
            }

            node.end++;
        }

        public int search(String word) {
            TrieNode node = root;

            for (int i = 0; i < word.length(); i++) {
                int path = word.charAt(i);

                if (!node.nexts.containsKey(path)) {
                    return 0;
                }

                node = node.nexts.get(path);
            }

            return node.end;
        }

        public int prefixNumber(String prefix) {TrieNode node = root;

            for (int i = 0; i < prefix.length(); i++) {
                int path = prefix.charAt(i);

                if (!node.nexts.containsKey(path)) {
                    return 0;
                }

                node = node.nexts.get(path);
            }

            return node.pass;
        }

        public void delete(String word) {
            if (search(word) > 0) {
                TrieNode node = root;
                node.pass--;

                for (int i = 0; i < word.length(); i++) {
                    int path = word.charAt(i);
                    TrieNode next = node.nexts.get(path);

                    if (--next.pass == 0) {
                        node.nexts.remove(path);
                        return;
                    }

                    node = next;
                }

                node.end--;
            }
        }
    }
```

## 思路



### 1. 【一句话核心】

**“以路代点，前缀共享”**：将单词拆解为字符路径，公共前缀复用相同的树枝（节点），通过节点上的 `pass`（经过次数）和 `end`（结尾次数）两个计数器来统计前缀频率和单词词频。

### 2. 【算法技巧操作】

- **两种存储策略的权衡**：
  - **数组版 (`Trie`)**：`new TrieNode[26]`。
    - *优势*：访问速度极快（数组下标索引），无哈希冲突开销。
    - *局限*：空间浪费（稀疏时），且只能处理特定字符（如 'a'-'z'）。
  - **哈希表版 (`Trie2`)**：`HashMap<Integer, TrieNode>`。
    - *优势*：支持所有 ASCII/Unicode 字符，按需分配空间。
    - *局限*：哈希运算有常数时间开销，单个节点内存占用较大。
- **剪枝优化 (Lazy Deletion)**：
  - 在 `delete` 操作时，如果发现某个子节点的 `pass` 值减为 0，说明后面已经没有有效单词了，直接把这个子节点置为 `null`（或 `remove`），切断整条树枝，防止悬挂无用的空节点。
- **防御性删除**：
  - 删除前必须先调用 `search(word) > 0` 确认单词存在。如果不检查直接删，会导致 `pass` 计数器减成负数，破坏整棵树的数据一致性。

### 3. 【图解原理】

假设我们依次插入单词 **"abc"** 和 **"ab"**。

1. **插入 "abc"**：沿途节点的 `pass` 全部 +1，终点 'c' 的 `end` +1。
2. **插入 "ab"**：沿途节点的 `pass` 再次 +1，终点 'b' 的 `end` +1。

可以看到，'a' 和 'b' 节点的 `pass` 变成了 2，说明有两个单词经过它们（即有两个单词以 "ab" 为前缀）。

![image-20260131205126672](%E5%89%8D%E7%BC%80%E6%A0%91%E5%8E%9F%E7%90%86%E5%92%8C%E4%BB%A3%E7%A0%81%E8%AF%A6%E8%A7%A3.assets/image-20260131205126672.png)

- **Pass (P)**: 有多少个单词**路过**这里（即：以此路径为**前缀**的单词数）。
- **End (E)**: 有多少个单词**停止**在这里（即：以此路径为**完整单词**的单词数）。

### 4. 【代码逐行精读】

重点讲解 **`insert`** 和 **`delete`** 的核心逻辑（以数组版为例）。

**插入操作 (`insert`)**

```java
public void insert(String word) {
    TrieNode node = root;
    node.pass++; // 根节点 pass 也要加，统计总词数

    for (int i = 0; i < word.length(); i++) {
        // 计算字符对应的数组下标 (0-25)
        int path = word.charAt(i) - 'a';

        // 如果路不存在，先铺路
        if (node.nexts[path] == null) {
            node.nexts[path] = new TrieNode();
        }

        // 往下走，沿途 pass + 1
        node = node.nexts[path];
        node.pass++;
    }
    // 单词结束，end + 1
    node.end++;
}
```

**删除操作 (`delete`) - 最难点**

```java
public void delete(String word) {
    // 【易错点】必须确认单词存在才能删！否则 pass 可能会被减乱
    if (search(word) > 0) {
        TrieNode node = root;
        node.pass--; // 根节点 pass 减 1

        for (int i = 0; i < word.length(); i++) {
            int path = word.charAt(i) - 'a';

            // 【核心剪枝技巧】
            // 先把下一个节点的 pass 减 1。
            // 如果减完变成了 0，说明那个分支后面全是废弃节点了。
            // 直接 node.nexts[path] = null 斩断，不需要再往下走了！
            if (--node.nexts[path].pass == 0) {
                node.nexts[path] = null;
                return;
            }

            node = node.nexts[path];
        }
        // 如果没触发剪枝，最后把终点的 end 减 1
        node.end--;
    }
}
```

### 5. 【死记硬背点 / 易错点】

1. **Delete 必须先 Search**：在执行 `delete` 之前，必须先判断 `search(word) != 0`。如果你去删除一个不存在的单词，会导致路径上所有节点的 `pass` 值错误地减 1，整棵树就毁了。
2. **ASCII 转换**：
   - 数组版：`char - 'a'` 是为了把字符映射到 `0~25` 的下标。
   - Map 版：直接用字符本身（自动装箱为 Integer）作为 Key，不需要减 'a'。
3. **剪枝时机**：是 `--node.nexts[path].pass == 0`。注意是**先减再判断**。意思是“如果我拿走这个单词的贡献后，那个节点没人经过了，那就直接拆除”。

### 6. 【复习闪卡】

1. **Q: 前缀树节点中的 `pass` 和 `end` 分别代表什么？**
   - A: `pass` 代表有多少个单词以当前路径为**前缀**（经过）；`end` 代表有多少个单词以当前路径**结尾**（词频）。
2. **Q: 为什么删除单词前要先 `search`？**
   - A: 为了防止删除不存在的单词导致 `pass` 计数器减为负数，破坏树的正确性。
3. **Q: 数组实现 (`TrieNode[]`) 和 哈希表实现 (`HashMap`) 的主要区别是什么？**
   - A: 数组实现速度快但空间可能有浪费，且仅限特定字符范围；哈希表实现通用性强（支持所有字符），但有常数时间开销。



# 3. 静态数组方式实现前缀树

测试链接 : https://www.nowcoder.com/practice/7f8a8553ddbf4eaab749ec988726702b

## 代码

```java
import java.util.Arrays;

public class Code02_TrieTree {
    public static int MAXN = 150001;

    public static int[][] tree = new int[MAXN][26];

    public static int[] end = new int[MAXN];

    public static int[] pass = new int[MAXN];

    public static int cnt;

    public static void build() {
        cnt = 1;
    }

    public static void insert(String word) {
        int cur = 1;
        for (int i = 0; i < word.length(); i++) {
            int path = word.charAt(i) - 'a';
            if (tree[cur][path] == 0) {
                tree[cur][path] = ++cnt;
            }
            cur = tree[cur][path];
            pass[cur]++;
        }
        end[cur]++;
    }

    public static int search(String word) {
        int cur = 1;
        for (int i = 0; i < word.length(); i++) {
            int path = word.charAt(i) - 'a';
            if (tree[cur][path] == 0) {
                return 0;
            }
            cur = tree[cur][path];
        }
        return end[cur];
    }

    public static int prefixNumber(String pre) {
        int cur = 1;
        for (int i = 0; i < pre.length(); i++) {
            int path = pre.charAt(i) - 'a';
            if (tree[cur][path] == 0) {
                return 0;
            }
            cur = tree[cur][path];
        }
        return pass[cur];
    }

    public static void delete(String word) {
        if (search(word) > 0) {
            int cur = 1;
            pass[cur]--;

            for (int i = 0; i < word.length(); i++) {
                int path = word.charAt(i) - 'a';

                if (--pass[tree[cur][path]] == 0) {
                    tree[cur][path] = 0;
                    return;
                }
                cur = tree[cur][path];
            }

            end[cur]--;
        }
    }

    public static void clear() {
        for (int i = 1; i <= cnt; i++) {
            Arrays.fill(tree[i],0);
            end[i] = 0;
            pass[i] = 0;
        }
    }
}
```



## 思路

这是 **前缀树（Trie）的静态数组实现版**。

在算法竞赛（ACM/ICPC）或笔试中，这是**最常用**的写法。相比于之前的“动态对象版”（`new Node()`），这种写法利用**静态数组**模拟指针，避免了频繁 `new` 对象带来的时间和内存开销，速度极快。



### 1. 【一句话核心】

**“一张大表走天下”**：不再创建一个个对象节点，而是预先申请一个巨大的二维数组 `tree[][]`。**行号**代表节点 ID，**列号**代表字符路径，格子里的**数值**代表下一个节点的 ID（相当于指针）。

### 2. 【算法技巧操作】

- **指针变索引**：
  - 对象版：`node.nexts[path] = new Node()`
  - 数组版：`tree[cur][path] = ++cnt`。`cnt` 是全局计数器，每需要一个新节点，就分配下一个整数 ID 给它。
- **三数组并行**：
  - `tree[MAXN][26]`：存树的结构（路）。`tree[u][c] = v` 表示从节点 `u` 经过字符 `c` 到达节点 `v`。
  - `pass[MAXN]`：存每个节点 ID 的经过次数。
  - `end[MAXN]`：存每个节点 ID 的结尾次数。
- **0 与 1 的约定**：
  - 通常用 **1** 号作为 **根节点 (Root)**。
  - **0** 表示 **空/不存在**（类似于对象版的 `null`）。如果 `tree[u][c] == 0`，说明没路。

### 3. 【图解原理】

假设我们依次插入单词 **"abc"** 和 **"ab"**。

**逻辑视角 vs 物理存储视角：**

- **逻辑上**：依然是一棵树，从根往下分叉。
- **物理上**：数据是平铺在二维数组里的。

![image-20260131223929989](%E5%89%8D%E7%BC%80%E6%A0%91%E5%8E%9F%E7%90%86%E5%92%8C%E4%BB%A3%E7%A0%81%E8%AF%A6%E8%A7%A3.assets/image-20260131223929989.png)

**图解说明：**

1. **Row 1 (Root)**：
   - `insert("abc")`：遇到 'a' (列0)。`tree[1][0]` 原本是 0，现在分配新 ID **2**。
   - `pass[1]` 变成 1，`pass[2]` 变成 1。
2. **Row 2 (Node 'a')**：
   - 接着走 'b' (列1)。`tree[2][1]` 分配新 ID **3**。
3. **Row 3 (Node 'b')**：
   - 接着走 'c' (列2)。`tree[3][2]` 分配新 ID **4**。
   - 单词 "abc" 结束，`end[4]++`。
4. **插入 "ab"**：
   - 从 Root (Row 1) 走 'a' -> 去 Row 2。
   - 从 Row 2 走 'b' -> 去 Row 3。
   - 单词 "ab" 结束，`end[3]++`。
   - 沿途 `pass` 都会增加。

### 4. 【代码逐行精读】

**全局变量定义**

```java
// MAXN: 估算所有单词的总字符数之和。
// 比如 100个单词，平均长度10，MAXN 至少要 1000。
public static int MAXN = 150001;

// tree[i][j]: 节点 i 经过字符 j (0-25) 到达哪个节点？
// 值为 0 表示没路，值为 k 表示去往节点 k
public static int[][] tree = new int[MAXN][26];

// 记录节点 i 的结尾次数
public static int[] end = new int[MAXN];
// 记录节点 i 的经过次数
public static int[] pass = new int[MAXN];

// 全局分配器：目前用到了哪个 ID
public static int cnt;
```

**插入操作 (`insert`)**

```java
public static void insert(String word) {
    int cur = 1; // 从根节点 1 开始
    pass[cur]++; // 这一点左神代码里有时候不加，但严格来说根节点 pass 也要增加

    for (int i = 0; i < word.length(); i++) {
        int path = word.charAt(i) - 'a';
        
        // 如果当前格子是 0，说明没路，需要新建
        if (tree[cur][path] == 0) {
            // ++cnt：分配下一个可用的行号给它
            tree[cur][path] = ++cnt;
        }
        
        // cur 跳到下一个节点 ID
        cur = tree[cur][path];
        pass[cur]++;
    }
    end[cur]++; // 单词结束，记录词频
}
```

**删除操作 (`delete`)**

```java
public static void delete(String word) {
    if (search(word) > 0) { // 必须先查存在，防止减成负数
        int cur = 1;
        // 左神这份代码这里没有 pass[cur]--，逻辑上其实根节点也要减，但不影响后续运行
        // 如果上面 insert 维护了 root 的 pass，这里最好也维护

        for (int i = 0; i < word.length(); i++) {
            int path = word.charAt(i) - 'a';

            // 【剪枝优化】
            // 如果下一个节点的 pass 减完变成 0 了
            // 说明该节点及其子树都没用了
            if (--pass[tree[cur][path]] == 0) {
                tree[cur][path] = 0; // 直接断开连接！(置为0等于null)
                return;
            }
            cur = tree[cur][path];
        }
        end[cur]--;
    }
}
```

**清空 (`clear`) - 多测试用例必备**

```java
public static void clear() {
    // 只需要清空用过的部分 (1 到 cnt)
    // 不需要遍历整个 MAXN，节省时间
    for (int i = 1; i <= cnt; i++) {
        Arrays.fill(tree[i], 0);
        end[i] = 0;
        pass[i] = 0;
    }
    // 【易错】千万别忘了重置 cnt = 1，准备下一轮
    // (代码里 build 方法重置了 cnt，或者在这里重置)
}
```

### 5. 【死记硬背点 / 易错点】

1. **MAXN 设置**：`MAXN` 的大小不是单词个数，而是**所有单词字符总长度**的上限。如果题目给的总字符数是 $10^5$，你的 `MAXN` 就要开得比 $10^5$ 大。
2. **cnt 重置**：在 OJ 题目中，通常会有多组测试数据。每组开始前必须重置 `cnt = 1` 并 `clear` 数组，否则上一组的数据会残留。
3. **Root = 1**：为了区分“空”（0），我们通常浪费掉索引 0，从 1 开始做根节点。
4. **空间换时间**：这是一个经典的空间换时间做法，`int[MAXN][26]` 可能会占用较大内存（约 $150000 \times 26 \times 4$ 字节 $\approx 15$ MB），注意题目内存限制。

### 6. 【复习闪卡】

1. **Q: 静态数组 Trie 中，`tree[u][path] = v` 的含义是什么？**
   - A: 表示从节点 ID 为 `u` 的节点，经过字符 `path`，到达节点 ID 为 `v` 的节点。
2. **Q: 为什么静态数组版比对象版快？**
   - A: 避免了大量的 `new Object` 开销（内存分配+GC），且数组访问具有更好的缓存局部性。
3. **Q: `delete` 操作中 `tree[cur][path] = 0` 这一行起什么作用？**
   - A: **断链（剪枝）**。当发现子节点的 `pass` 为 0 时，说明后续无单词经过，直接把路封死（置为0），实现逻辑删除。
